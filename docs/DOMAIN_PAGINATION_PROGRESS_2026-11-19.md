# Phase D：域名分页与有界渲染（2026-11-19）

承接入口优化 `7cff7c8`，本批覆盖 DNSHE / Cloudflare / DigitalPlat / DNSPod / 阿里云 / 华为云 / Vercel / 自定义八类列表。数据库 schema 仍为 v5，不新增或重建业务表，不改上游同步/续期协议、AES_KEY 或通知。

## 为什么不能只在页面 slice

旧前端的概览、菜单数字、全局搜索、Cloudflare 注册来源与日期，都依赖各服务商的完整域名数组。直接把数组改成 100 条，会造成全量统计漏算、跨页搜索失败和注册来源错误。因此列表、摘要、搜索、关联信息拆成独立查询。

## API

- `GET /api/domains/page?provider=dnshe&limit=100`
  - 各来源页最多 100 条；托管商返回 `domains`，自定义返回 `custom_domains`。
  - `account_id` 对托管商为账号筛选，对自定义为分组筛选；另支持 `search`、托管商 `status`、`cursor` 与 `focus`。
  - 返回 `total`、全筛选账号/分组计数、`next_cursor` 和本页所需的跨来源注册信息 `hints`。
  - 数据实体读取使用 SQL `id > after AND id <= ceiling ORDER BY id ASC LIMIT limit+1`，没有 OFFSET，也没有取出全部实体后在浏览器切片。
  - 游标是有版本的 UTF-8/Base64 JSON，绑定来源、账号/分组、搜索、状态。长度/数字范围/作用域非法返回 400，不能把旧筛选游标用于新筛选。
  - `focus` 根据归一化域名定位并从目标 ID 开始读页，不需要逐页下载到目标为止。
- `GET /api/domains/summary?timezone_offset=-480`
  - 独立全量摘要，复用迁到 `shared/` 的纯聚合函数，按归一化域名跨源去重。
  - 账号、来源总数、过期与永久判断、最近注册、预警及月份计数不会受当前页/账号筛选影响。
  - 摘要只返回最近 6 条、预警 8 条、每月前 20 条及全量计数；不会把一整月 10,000 条列表返回给浏览器。
  - 手动日期覆盖与有效 RDAP 缓存从服务端读取，不依赖先访问 Cloudflare 页面或某台设备的历史本地缓存。
  - 月桶与无时区 SQLite 时间按请求端当前时区偏移解释，避免 Worker UTC 与浏览器 UTC+8 月界不同；偏移参数有界。
  - 使用四个只读查询；到期缓存与覆盖合并查询，保留冷启动查询预算余量。
- `GET /api/domains/search?search=关键词`
  - 对完整库存的精简名称索引搜索，不只搜当前页。
  - 兼容 Unicode 部分匹配及 Punycode；每来源返回真实命中总数与最多 8 条候选。
- 旧 `GET /api/domains` 仍保持完整列表契约，供旧客户端与内部操作兼容；新 UI 不再用它下载全库。
- 自定义账号元数据支持 `GET /api/custom-groups/overview?include_domains=0`，避免仅取账号时附带所有域名。

以上端点均在原会话认证下，不返回账号 API Key/Secret。数据库读取失败传播为失败，不以成功零计数或不完整摘要兜底。

## 前端

- `useDomainCatalog` 只自动加载当前服务商页；登录后取轻量摘要和账号，不再无条件下载七家托管商全量域名。
- 每来源保留一个最多 100 条的当前页与游标历史，下一页/上一页/返回首页不累积所有行；保留原有账号分组、卡片操作、同步和弹窗。
- 计数明确区分全筛选总数与“本页”，菜单和概览使用服务端摘要。数据库错误展示失败/重试，不把失败显示为“没有域名”。
- 对摘要/搜索的关键结构和条数上限做响应检查；分页若返回超过 100 条、假成功或错误格式则拒绝展示，不通过悄悄切片掩盖后端契约问题。
- 全局搜索有 250ms 防抖、取消与旧响应保护；点击候选/预警/时间轴，直接定位对应来源和域名，放宽账号筛选、展开分组并等待 lazy DOM 出现后滚动。
- 分页/筛选/搜索/后端身份改变时中止旧请求；登出和会话改变清页与摘要。迟到的 401 不能注销新会话，正常取消不会作为控制台错误。
- 自定义列表不再读取旧的全量域名 localStorage 缓存，未删除用户的历史缓存。
- 首访自定义页只读取账号元数据，不重置已定位的页；显式刷新/写操作完成后才重置游标。元数据请求按会话/后端身份取消；失败时从本页已确认的账号 ID/名称渲染域名，并显示元数据错误而非吞掉整页。
- Cloudflare 跨源注册日期与来源通过本页 `hints` 判断，不依赖 DNSHE/DP 恰好加载了同一页。RDAP 查询按最多 15 个目标分片，避免 100 条列表被原 50 目标接口截断。
- DNSHE 线路推断保留根域 NS 查询，但只查当前页涉及的根域与轻量配置，不在登录后对全库做查询。
- 时间轴柱高、数字和总数读完整 `count`，展开 DOM 只用 20 条摘要，并明确提示“展示前 20 条”。

## 验证

- 新增真实 SQLite/共享 Worker API 集成用例，以及 React 生命周期与有界 DOM 用例；接入 `test:invariants`。
- 10,000 条 DNSHE 记录通过 100 个游标页遍历，无重复/遗漏；普通分页测试禁止调用全库投影/搜索扫描，保证走 SQL keyset。
- 八类来源分页与总数、续期改变到期排序、翻页间删除、筛选游标混用、Unicode 游标、跨页搜索/定位、摘要独立性、同域去重、日期覆盖/缓存、时区边界、认证/参数和读取故障均有回归。
- React 测试验证旧筛选响应不能覆盖新页、身份清理；10,000 条库存对应列表只渲染传入的 100 张卡片，时间轴只渲染 20 行并保留全量计数。
- 本地 Chromium + 真实 Node/SQLite + 20,900 条测试记录：八类列表每页 ≤100 张卡片；DNSHE 翻到 101–200 后能返回 1–100；搜索和 CF → DNSHE 交叉跳转能定位第 9,990 条；首访自定义能直接定位第 10,000 条。删除该自定义测试记录后，列表总数 10,000 →9,999，跨源去重概览 20,899 →20,898，时间轴始终只渲染 20 行。
- 浏览器控制台无错误；资源时间记录中只有 `/api/domains/page`、`summary`、`search`，没有旧全量列表请求。未调用真实服务商或修改生产数据；测试会话、临时服务和浏览器已关闭，临时测试数据保留在批准的 Temp 目录用于诊断。
- 提交前 `npm run verify:all` 通过：共 310 个不变量/集成用例（本批增加 22 个），Worker/Node 类型与构建、主题、发布包、隔离 workerd/Node 冒烟、Docker 源码边界检查通过；自建前端构建也通过。
- 普通入口业务闭包 63.38KB gzip、含框架首屏模块 119.49KB；自建为 63.31KB /119.42KB，均在 80KB/140KB 门禁内。
- 实际全量门禁、浏览器检查与发布结果以执行日志和对应提交的 Actions 为准，不将本地模拟等同真实生产账号验收。

## 明确限制

- 本次为了稳定翻页采用 ID 升序，不沿用会在续期时变化的到期时间排序。卡片仍显示日期与到期状态；全量紧急排序由概览预警提供。
- `ceiling` 是游标上界，不是事务快照/generation。并发插入较小的哈希 ID、账号迁移、筛选字段改变等，可能需要刷新首页才出现；不承诺持续变化库存的严格快照遍历。应用写操作完成后刷新并重置游标。
- 全量摘要和 Unicode 搜索仍在服务端处理精简投影，复杂度 O(N)；计数和关联查询也仍有扫描成本。没有增加 FTS、物化摘要或新的索引。10,000 条 Node/SQLite 验证不等于 Workers 免费计划 CPU 限额验收，超大库存需要下一阶段预计算/索引化。
- 当前时区偏移不包含未来夏令时规则，不声称跨夏令时的无时区历史时间已完全标准化。
- 账号下拉与自定义账号元数据仍不是分页，本批有界的是域名列表及月份明细。
- 实际上游注册/续期/解绑、弱网和生产全量数据 E2E 不在隔离测试保证范围。

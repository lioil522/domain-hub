# 同步写入与检查点共用租约判断

在 `3b5ab9c` 上用隔离 SQLite 复现了两种进度分裂：

- 在租约截止前 1ms 暂存一页，写入行和检查点分别取时间。前一条 SQL 命中，后一条更新 0 行；`batch()` 本身成功，随后在 JS 抛错并不能回滚已经提交的行。恢复时再次暂存同一页可能遇到主键冲突。
- 队列驱动的 Cloudflare 最后一页先提交库存替换、删除候选及 generation 清理，再单独提交外层 `sync_work.cursor`。第二次提交失败会留下旧游标，此时用来续读的 generation 已经不存在。

## 提交方式

同步工作在网络请求和异步准备完成后，为本次数据库提交生成一个检查点计划。业务 SQL 与游标 SQL 都使用同一时刻、任务 ID、`running` 状态和租约令牌；游标写入成功后才更新内存进度。适用于开始快照、暂存页、配额、DNS 批次（含失败次数）、库存写入、续期日志和同步完成通知。

Cloudflare 队列任务在获取页面及复核凭据后才生成计划，将 CF generation 和队列租约一起用于页面事务。外层游标在 CF 游标推进或 generation 删除之前更新，此时两个租约条件都可检查。两步均在同一个 `batch()` 内，SQL 错误会使本页库存、候选、CF 进度和队列游标一起回滚。独立 CF 分页使用自身的 generation 和租约；从绑定账号构建的 CF 客户端同时核对当前凭据。

通知先完成加密、验长和分块，然后才绑定生产者租约。独立到期扫描也在此时检查中断、取一次时间，密文入队与扫描游标据此共同提交。通知**入队**与外部通道**送达**仍是不同状态。

续期发送前的原有日志查询同时检查工作租约；查询返回后再检查中断。已经留下 `attempting` 但结果不明时仍只读核对。租约判断是构造批次时的准入判断，事务中仍核对数据库里的令牌；既不是数据库硬实时截止，也不使远端 POST 和本地事务原子化。已经发出的请求无法撤回。

## 验证

用可控时钟覆盖租约截止前 1ms、恰好到期、4 个 DNS 结果同批提交、读页/加密过程中租约失效，以及续期日志落库后任务暂停。Cloudflare 两页测试在最终队列游标处注入 SQL 失败，验证存量未提前删除、恢复只重新获取第 2 页。隔离 workerd/D1 在相反方向注入 CF 检查点失败，验证先执行的队列游标也回滚，随后重试并完成。同组测试保留了不确定续期不重复 POST、通知独立重试和过期租约不可覆盖新持有者的既有要求。

复现：`npm run test:integration:cf-sync`、`npm run test:integration:notifications`；完整构建及双运行时冒烟使用 `npm run verify:all`。无 schema 迁移或新增调度资源。

## 账号改绑时，谁还有权提交？

在 `a0de23a` 的隔离 SQLite 上，普通任务已暂存一页并停在 `write`。用假客户端完成改绑、尚未排入替代任务时，库存仍为原来的 `[42]`，但旧工作仍是 `running`，租约令牌未清空。这个对照确认的是旧提交权限未被撤销，不是生产库存损坏记录。

- **账号更新或删除**：同一事务撤销该账号的活跃工作、刷新相关动作、清理相关 DNS／配额缓存及 CF 分页状态。改绑保留正式库存，待新快照成功后再做差集清理。事务失败时原绑定、缓存和租约一起保留。仅改别名只写别名；凭据变更保存前比对验证所用的旧绑定，并发编辑冲突返回 `409`。
- **在途结果**：持久队列从同一账号行校验任务指纹并构建客户端。库存、DNS、游标以及续期发送前的所有权检查在 SQL 中比对账号 ID、服务商及存储形态的凭据。独立 CF 客户端的页认领和页提交也在 SQL 中检查同一绑定；旧页不能推进或清理新一轮库存。任务表只存指纹，比较用的凭据不写进游标。改绑不会清掉结果不明的续期记录。
- **重新排队**：替代同步仍在账号事务之后排入。旧执行器在这个间隔已经失效；如果排队失败，可重新发起同步。较早读到账号数据的入队／重试调用也须核对绑定，不能取消新持有者或清掉它的暂存行。

专项测试用可控的本地响应覆盖 DNS 请求跨越改绑、删除、别名变更，验证失败回滚、两个改绑请求竞争，以及独立 CF 指纹预检与 SQL 执行之间的变更。本地 workerd/D1 冒烟还检查了已更改绑定的队列游标不可推进，以及删除后租约确实撤销。

保证范围是持久队列和使用已绑定客户端的 CF 分页。`runDailySyncAndRenewal` 的非 CF 旧同步路径、默认账号初始化深度同步、注册后的回填及交互式 DNS 操作有各自的写入入口；不能从这些队列测试推断它们受同一条件保护。

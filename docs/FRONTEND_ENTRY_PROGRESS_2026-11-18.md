# Phase D：前端入口体积（2026-11-18）

承接已发布的 Dashboard 统计修复 `b1043b1`。本批只做 JavaScript 按需加载与入口预算，不改数据库、服务商 API、密钥、通知或列表分页。

## 测量口径与结果

以同一套 Vite 普通生产构建、Node `gzipSync` 默认压缩参数测量，KB = 1,000 字节：

| 指标 | 改造前 | 改造后 |
|---|---:|---:|
| 业务入口及全部静态业务依赖 | 138.08KB gzip | 61.08KB gzip |
| 首屏静态模块 JS（含 React 与图标） | 194.19KB gzip | 117.19KB gzip |
| 普通业务入口原始字节（UTF-8） | 476,379 | 195,446 |

业务入口减少约 **56%**，首屏模块 JS 减少约 **40%**；达到原分析的业务入口 ≤80KB gzip 目标。没有抬高 Vite warning 阈值，也没有只把代码移到首屏仍会立即下载的 vendor chunk。

上表不是页面总流量：CSS、`theme-init.js`、图片另计；CSS 未在本批优化。访问某项业务时仍会下载该项完整代码，不宣称所有页面合计代码减少或得到新的 LCP/INP 分数。

## 真正的懒加载边界

### Scanner

- 根控制器不再静态导入或调用 `useScanner`。`ScannerHost` 首次访问注册/查重页面时才导入 `ScannerFeature`，其 hook、规则解析器、英文词库、邮编、拼音与地理数据一起按需进入。
- 登录页与概览页不初始化词库、不播种词库存储、不读取/验证完整扫描检查点。
- 访问过后，切换菜单保持 Scanner hook 挂载，继续保留运行任务、草稿、结果与断点；不渲染隐藏的列表和词库 portal。
- `ScannerHost` 按后端地址与会话身份设 key；登出、会话失效或切换后端会卸载旧 hook，由已有扫描 cleanup 保存连续完成检查点并中止任务。
- 线路解析也需要的根域名目录抽到轻量 `scanner-root-domains.ts`，沿用原存储键与默认值，不通过 `scanner-storage → checkpoint → planner → rulegen` 把词库重新拉回首屏。目录修改通过回调同步到线路设置。

### 弹窗

- `app/modals.tsx` 集中注册绑定/编辑账号、建域/删域、DNSHE/DP NS、DNSHE/共用 DNS 面板、CF 注册信息、备份操作、自定义分组/账号/域名弹窗。
- `lazyModal` 在组件边界检查 `open` 或选中对象，关闭时直接不挂载 lazy 组件。仅把弹窗改成 `React.lazy`，但仍无条件渲染，会马上下载；本批明确避免这一点。
- 每个弹窗拥有独立 Suspense 与错误边界，慢下载不会把背后的整个页面替换成骨架。加载中可取消；导入失败提供关闭与手动重新加载提示，提醒重新加载会丢失未保存表单。
- 只有加载中/错误状态使用临时遮罩和焦点陷阱，真正弹窗加载成功后使用自己的外壳，避免嵌套遮罩/焦点陷阱。
- 页面与设计系统也补上加载失败兜底；切换页面可恢复另一个正常页面。没有自动刷新、无限重试、重放写请求。

## 发布门禁

`frontend/tooling/bundle-budget.ts` 在 Vite `generateBundle` 的 post 顺序检查真正的静态依赖图；先等 Vite 注入 preload 依赖映射，再测量最终输出字节：

1. 从全部 entry chunk 递归追踪静态 `imports`，包含任意层级的共享业务 chunk。
2. 业务闭包 gzip ≤80,000 字节；只有固定的 React/图标框架 chunk 不计入业务预算，新 vendor/共享业务 chunk 仍计入。
3. 包括框架的首屏模块 JS gzip ≤140,000 字节。
4. Scanner hook/组件、规则数据与重型弹窗若回到静态闭包，即使很小也失败。
5. 缺失 entry 或无法计量的外部静态导入不能按零字节放行。

门禁直接参与普通、自建、Docker 隔离源码构建与既有 CI。没有在生产资产中输出源文件清单或构建报告。

## 限制与后续

- Scanner 第一次打开仍会一次下载约 42.8KB gzip 的 feature chunk；本批优化的是未使用 Scanner 的首屏，而不是继续细拆扫描内部数据。
- 自定义弹窗仍共用一个 chunk；打开其中一个会下载该组弹窗，首屏不下载。
- 根控制器的其他 feature hook 仍在原位置。本批没有引入 query 层、重构所有 feature 生命周期或更改请求策略。
- 大列表分页/虚拟化、背景图和 CSS 预算不在本批范围。
- 本地 mock 浏览器检查不等于真实账号扫描/注册 E2E；不宣称跨设备、弱网 Core Web Vitals 已验收。
